# Keyboard

Everything in the app can be reached from the keyboard. The way around is the same on every page, and each page adds its own keys on top. Press `?` on any page to see the keys that work there.

Letters do nothing while you are typing in a field. Press `Esc` to leave the field first. `Cmd` on a Mac is `Ctrl` elsewhere.

## Reach a page

Press `g`, then a letter. If you pause after `g`, a popup lists the next keys.

| Keys | Page |
| --- | --- |
| `g` `i` | Inbox |
| `g` `g` | Goals |
| `g` `p` | Projects |
| `g` `k` | Knowledge |
| `g` `r` | Graph |
| `g` `l` | Timeline |
| `g` `t` | Tags |
| `g` `d` | Stats |
| `g` `s` | Settings |

`Cmd+K` opens search from anywhere.

## Move around

| Keys | What it does |
| --- | --- |
| `.` or `F6` | Next section of the page, such as header or content |
| `,` or `Shift+F6` | Previous section of the page |
| `;` | Jump between the sidebar and the page |
| `j` `k` or arrows | Move between the items of a section |
| `Enter` | Open the item |
| `Esc` | Go back one level: out of a field, then close the drawer |

Inside a drawer or a dialog, `.` and `,` go through its own sections, and the keys of the page behind it are paused.

## Act on the page

`n` starts something new and `/` filters, on the pages that have those actions.

| Page | Keys |
| --- | --- |
| Inbox | `e` archive, `h` snooze, `j` `k` next and previous |
| Project board | `h` `l` `j` `k` move between cards, `Shift+H` `Shift+L` move the card to the next column, `m` move it to another project |
| Task drawer | `t` switch between text and code |
| Graph | `+` zoom in, `-` zoom out, `0` fit the view |
| Editor | `Cmd+S` save |

## Change a key

Go to **Settings**, **Shortcuts**, and press **Change** on a row. Press `g` first to record a two-step key.

Some keys are refused: those the browser keeps for itself, such as `Cmd+T` or `Cmd+L`, and `.`, `,`, `;` and `?`, which every page shares. Choices are saved in your browser.
