# Split the Settings page into tabs

Move the Settings page to tabs so it has room to grow: General, Editor, Shortcuts and Workspace. Tabs with nothing in them yet stay hidden until their task adds content.

## Checklist

- [ ] Editor settings and keyboard shortcuts each sit in their own tab
- [ ] The open tab is in the URL, so a reload or a shared link keeps it
- [ ] Tabs work by keyboard and are named for screen readers
- [ ] `go.settings` and the rail still reach the page
- [ ] Existing settings end-to-end tests pass, updated for the tabs
