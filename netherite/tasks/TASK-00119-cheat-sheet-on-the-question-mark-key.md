# Cheat sheet on the question mark key

`?` shows every key that works right now, so the keys can be discovered from any page.

## Checklist

- [ ] `?` opens the sheet on every page, and not while typing
- [ ] It is built from the registry, with no separate list to maintain
- [ ] The current page's keys come first, then moving around, then reaching a page
- [ ] It shows rebound keys and leaves out cleared ones
- [ ] An e2e test opens it on two pages and sees different page keys
